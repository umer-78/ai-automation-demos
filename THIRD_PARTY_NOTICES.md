# Third-party notices

Small UI pieces adapted from open-source component libraries. Each file names its source in a comment at the top.

| Component | Used in | Source | Licence |
|---|---|---|---|
| Border Beam, Shimmer Button | both demos | [Magic UI](https://magicui.design) | MIT |
| Number Ticker, Animated List (as RevealList) | Demo 1 | [Magic UI](https://magicui.design) | MIT |
| Decrypted Text | Demo 1 | [React Bits](https://reactbits.dev) by David Haz | MIT + Commons Clause |

Benchmark figures in Demo 1's sample data come from LocaliQ's published 2026 search and Facebook ads benchmark reports, linked in the code and on the dashboard. Lead facts in Demo 2's saved research link to their public source pages.

Fonts: Schibsted Grotesk (Demo 1) and Newsreader with Hanken Grotesk (Demo 2), all under the SIL Open Font License, bundled through Fontsource.
