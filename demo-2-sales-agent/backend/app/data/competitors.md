# Competitors (fictional, for this demo)

## Bastion Cloud: posture only
- Deep rule coverage, priced for large enterprises; most deals start above $60,000 a year.
- We win with mid-size teams that also need audit evidence and can't run two tools.

## Ledgerline: compliance automation only
- Fast SOC 2 checklists and an auditor network.
- No live cloud checks; evidence is a snapshot. We win when the buyer has had a near miss in the cloud.

## OpenGuard: open-source scanners
- Free and popular with engineers.
- No evidence trail, noisy alerts, and someone has to own it. We win when the security hire is stretched thin.

## How to talk about competitors
Never name a competitor in a first email. Lead with the customer's situation, not the comparison.
