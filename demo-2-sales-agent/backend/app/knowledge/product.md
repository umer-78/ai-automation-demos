# Acme Cloud Security: what we sell

Acme Cloud Security is a fictional company used for this demo.

## Product: Acme Guard

Acme Guard connects read-only to a customer's AWS, Azure and Google Cloud accounts and does three jobs:

1. **Finds risky configuration** (public storage buckets, over-privileged roles, unencrypted databases, open admin ports) within minutes of a change, not at the next audit.
2. **Keeps compliance evidence current** for SOC 2 and ISO 27001. Evidence is collected continuously and mapped to controls, so an audit window starts with a complete folder.
3. **Answers security questionnaires** from live evidence. Sales teams stop waiting on engineers to fill in 200-line vendor questionnaires.

Setup takes under a day. There is no agent to install.

## Ideal customer

- B2B software companies (SaaS, fintech, healthtech, developer tools, data and AI, vertical software).
- 50 to 1,000 employees. Large enough to be asked for SOC 2 or ISO 27001, small enough that security is a team of one to five people.
- Cloud-native: most workloads in AWS, Azure or Google Cloud.
- A reason to act now, in order of strength:
  1. A compliance milestone: a first SOC 2 or ISO 27001 audit, a Type I to Type II move, or a new framework for a new market.
  2. A new security leader (CISO, Head of Security) in their first 90 days.
  3. Hiring security or cloud engineers.
  4. A funding round (Series A to C), which is usually followed by enterprise deals and longer security reviews.
  5. Expansion into regulated industries or new regions.
- North America, UK and Ireland, Europe and Australia / New Zealand.

## Not a fit

- Fewer than 50 employees: usually too early and price-sensitive.
- Security vendors: they build this in-house.
- Agencies and IT services firms: their clients own the cloud accounts.
- Large enterprises (1,000+) that run mostly on-premise: long procurement, needs we do not cover.

- Plain language, short paragraphs, no buzzwords.

- One clear, low-pressure ask.
